    Method and updating

    How the dashboard decides what matters

    1. Baseline. 2024 JEE scores for the 56 JEE (third edition) indicators. A later internal self-assessment entered in data/score_history.csv becomes the “latest” score.
    2. Target. target_2029 in data/indicators.csv. Until the NAPHS Steering Committee sets targets, the default is the next capacity level for scores 1–3 and holding the current level for scores 4–5; D2.2 carries the score of 5 stated in the NAPHS.
    3. Tier. Critical (1–2, limited capacity), Advance (3, developed but not yet demonstrated), Sustain (4–5).
    4. Coverage. Each JEE priority action is matched to NAPHS strategic actions and rated Full, Partial or Not reflected.
    5. Flags. No NAPHS indicator row; one or no strategic action for an indicator below target; an action without a lead; JEE actions not reflected; no status reported; overdue or stale actions.

    How to update

    • Action status: edit data/naphs_actions.csv (status, progress_pct, target_date, last_updated, focal_person, evidence_url, remarks), or link the Google Sheet tracker described in the README.
    • New self-assessment scores: add rows to data/score_history.csv.
    • Targets and coverage ratings: edit data/indicators.csv and data/jee_recommendations.csv.

    Every commit to data/ rebuilds and republishes the page. A scheduled run every Friday afternoon refreshes the countdown and the overdue and stale flags. If a file has an error, the build stops, the published page stays as it was, and the error list appears in the Actions run summary.
